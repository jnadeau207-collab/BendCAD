# BendCAD

Experimental professional CAD kernel project for Bend2.

This repository is intentionally separate from the production Aethalgard CAD application.

## Legacy Aethalgard corpus

The `legacy/aethalgard/` tree preserves the pre-VibeCAD Aethalgard CAD/kernel implementation and supporting contracts as reference material for BendCAD.

Authoritative recovered source commit:

- repository: `jnadeau207-collab/reepo`
- commit: `eeca9ad782640f97bc15423e72319acea310d36f`
- preserved local-worktree snapshot: `1eab12971dcb22c0b75f9d3714ba377d86ab36b5`
- archive manifest commit: `213180dd5b2d0c805ae9610bf88be5cd82111b0f`

The legacy code is reference/oracle material. BendCAD is not a continuation of that C++/OCCT implementation and will not silently substitute OCCT for a Bend-native kernel.
