# C16.1 sheet metal — intent

Why the sub-packet looks the way it does. The contract states what
holds; this note states why each shape was chosen.

Profile extrusion, not direct B-rep. Bends and hems build through
`op_prism` over arc-carrying sketch profiles (the C09
chamfer/fillet-edge precedent), never as booleans. The prism hands
us caps with arc trims, cylinder bend walls, plane legs, the C04
validator and the C07 checker for free, plus STEP/tessellation that
already understand cylinders. Direct `pack()` construction would
re-prove all of that per profile and risk zero-trim faces the STEP
writer cannot carry.

Twelve explicit builders. Each admitted chain owns one profile
table with hand-derived arc flags; -x variants rotate 180 degrees
in-plane (a proper rotation: same combinatorics, same flags).
Mirror-plus-reverse transforms were rejected: they silently move
the start index and flip flag conventions, while explicit tables
are each proven linked by `sh_loop_closed` and each validated by
C04/C07 plus face-count pins at runtime.

Mid-length bends, square hems. The op carries no flange length, so
the bend line sits at mid-length (legs L/2, documented, oracled).
Closed hems are square folds (zero inner radius would be
degenerate arcs); the turn contributes exactly `t` to developed
length and `Lh*t` to area. Both choices keep every volume exact
with π as the only transcendental: the U area re-derives to a
form with no inverse trig after the first decomposition needed
`asin`, which F64 does not ship.

R/T 1.0. The enforced floor sits at the industry-standard minimum
radius with margin above any kernel thinness limit; R/T = 1.0
passes every profile and the boundary is pinned from both sides.
The true C04/C07 floor below it is unprobed (OM-rtfloor).

Two-dimensional laws, inherited 3D closure. The proven invariant
is profile loop linkage plus index validity over every production
profile (quantified, with teeth: a skipped index fails). Solid
closure (V-E+F, balance, loop return) is inherited from the
prism builder plus C04 plus C07 and evidenced per profile by
check-ok, exact face counts, exact volumes and independent
readers — the honest split for prism-built geometry.

Split dispatch. Extending `op_of_feat` to 13 fat branches trips
the C backend's 247-live-values segment limit (`bend -o` fails;
JS still emits). Sheet parsing therefore lives under its own
`op_is_sheet`/`op_of_sheet` arm checked first in `op_of`, exactly
the split the plan's C09 arity note prescribes.

Base-first gates. The chain check orders base before finiteness so
a non-sheet base reports `bend-base-not-admitted` instead of
collapsing into `degenerate-feature` on zeroed dimensions; every
other link keeps C09/C15 first-failure order.
