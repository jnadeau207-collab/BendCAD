# C16.2 surface modeling — contract (normative)

Four verbs over open shells: loft-open and sweep-open build open walls from C09-admitted
profiles, patch builds one bicubic Bezier face from 16 control points, thicken-open closes
an open shell into a solid. The `surf` query reports boundary edges by durable name with
area and boundary length. Open shells validate under the open-shell-1 profile (§7); only
thicken-open publishes closed solids, which validate on manifold-solid like every C09 part.

## 1. Positive list

- `(loft-open Z BOT TOP [(twist N)] [(continuity g1)])` — open walls of the C09 admitted
  planar loft: two axis-aligned rect loops (rect pairs kind 1 identical or kind 2
  distinct), G0 only. Builds 4 bilinear wall faces over 8 vertices and 12 line edges;
  no caps. Twist and continuity arguments flow through the shared C09 classifier, so a
  nonzero twist that breaks wall planarity refuses exactly as in C09.
- `(sweep-open (arc DEG) REGION [(guide ...) ] [(twist N)])` — open walls of a rect
  profile revolved about the z axis through DEG ∈ {90, 180, 270} with no end caps.
  The profile must be one axis-aligned rect loop strictly off the axis, any corner
  order; the builder canonicalizes it, so boundary names never depend on input order.
  Builds 4 walls per quarter (2 cylinder, 2 plane annulus) over the shared C09 sector
  machinery minus caps. Guide and twist arguments flow through the shared C09 gates.
- `(patch (pt X Y Z) × 16)` — one bicubic Bezier face through 16 finite control
  points in row-major order, with 4 cubic boundary edges. Rows, columns and corners
  must be pairwise bit-distinct. The control bounding box contains the patch by the
  convex-hull property; evaluated samples stay within 64 ulps of it (pinned).
- `(thicken-open BASE T)` — closed solid from the open shell BASE with finite wall
  thickness T > 0: each wall offsets ±T/2 along its normal with constructed side
  walls along the boundary loops. Admitted bases: rect patches (6-face slab),
  rect ducts (16-face tube), rect sectors (16-face annular tube). Tubes keep a
  through-channel (genus 1, single shell); the packer expresses no cavities.
- `surf NODE` — boundary report of an open-shell node: kind, face and boundary
  counts, one row per boundary edge (`edge nN.eI len [lo, hi] certified|estimated`),
  area, boundary length, control bounding box. Loft and sweep walls report certified
  outward-rounded intervals; patch curves and areas report subdivision estimates
  honestly labeled estimated (32×32 area grid, depth-10 boundary lengths).

## 2. Refusals (first-wins order per verb)

- loft-open: Z/holes/profile-validity (C09 strings) → `loft-open-not-planar`
  (unsupported-op) for kind-0 non-planar pairs → C09 `loft-not-certified`
  (uncertain) for non-rect pairs; `continuity-not-met` and `twist-not-admitted`
  inherit C09 verdicts through the shared classifier.
- sweep-open: `sweep-angle-not-certified` (unsupported-op) unless DEG ∈ {90,180,270}
  → `guide-not-admitted` → `twist-not-admitted` (both C09, unsupported-op) →
  C09 profile errors (`degenerate-feature`, `surface-not-representable`, axis codes)
  → `sweep-profile-not-admitted` (unsupported-op) for well-formed non-rect profiles.
- patch: `patch-degenerate` (invalid-input) for non-finite points, coincident rows,
  coincident columns, or coincident corners.
- thicken-open: `thicken-needs-open-shell` (invalid-input) unless BASE is a
  loft-open, sweep-open or patch node → `degenerate-feature` (invalid-input) unless
  T is finite and positive → `thicken-curvature-not-certified` (unsupported-op)
  unless a patch base is an exact rectangle with geometrically straight rows and
  columns (loft ducts and sweep sectors are planar/cylindrical by construction) →
  `thicken-consumes-shell` (invalid-input) when T collapses the inner channel.
- surf: `surf-needs-open-shell` (invalid-input) on closed, failed-side or unknown
  nodes; `unknown-node N` when no node evaluated (flat-verb wording).
- Inherited: `topology-not-certified-over-zone` on all four ops; `intersect` of
  features with open bases refuses `features-need-an-extruded-body`;
  `step-open-shell-not-in-profile` on STEP export and
  `archive-open-shell-not-in-profile` on archive of any open shell;
  check/classify/dist/interf/clearance/wall refuse `<verb>-needs-solid` on open
  shells (format `refused WHY | VERB | fix: thicken-open the shell to a solid
  first`). measure/eval print the stored mass record: enclosed volume 0 by
  convention (an open shell encloses nothing), area a loose certified bound;
  `surf` is the honest reporter.

## 3. Mass, intent, lineage

- Open shells store enclosed volume 0.0 with the loose 24·bm² area bound; every
  `mass`/`eval`/`measure` figure on an open node inherits that convention.
- Thickened solids store closed-form volumes: rectangle area × T for slabs,
  outer-minus-inner frustum volumes for ducts, outer-minus-inner annular-sector
  volumes for sectors (all F64 evaluation of exact formulas).
- Intent materials: loft-open, sweep-open and patch are baseless, hence `create`;
  thicken-open compares against its base and measures `add`. Counts stay `any`.
- Deleted-face lineage on thicken uses code 10; content-key tags are 35 loft-open,
  36 sweep-open, 37 patch, 38 thicken-open; the patch key terminates its 48
  expressions with tag 61.

## 4. Boundary names and durability

- Boundary edges are named `nN.eI` where I is the stored-bre​p edge index:
  loft 0–7 (bottom then top loop), sweep the station-0 then station-Q profile
  edges, patch 0–3. Names derive from canonical construction order, never from
  input loop order, so parameter edits keep every name stable.

## 5. STEP, archive, tessellation

- STEP refuses open shells by name (`step-open-shell-not-in-profile`, C12), and
  archive refuses them the same way (`archive-open-shell-not-in-profile`):
  both profiles carry closed solids only. Open shells persist through
  `show`/`apply` replay, which is byte-exact on re-evaluation.
- Thickened panels export as ordinary closed solids: slabs carry only plane
  faces, ducts plane rims with bilinear-bezier walls (planar geometry in the
  exact-corner representation the embedding check requires), sectors plane
  and cylinder faces. No builder emits cone or torus surfaces, so the
  section-3 kernel limit on CONICAL_SURFACE is untriggered; one E2E exports
  a tapered duct and asserts the exact face-kind split on read-back.
- Archive round-trips thickened solids (brep-preserving); extrema and section run
  over open shells with shell semantics. Tessellation evaluates a single-loop
  bezier-patch face on a fixed 8×8 interior grid through the shared bicubic
  evaluator (81 points, 128 triangles per face; the grid center is sampled)
  exactly when some control point leaves the corner plane by more than 1e-9
  relative to the face extent; planar bezier faces keep the boundary-ring
  triangulation exactly as before (welded, minimal). The grid is a
  documented resolution, not an error-certified approximation.

## 6. Complexity and budgets

- Builders are linear in output size (≤ 40 edges); the patch area grid is 1024
  cells and boundary subdivision depth 10. `surf` evaluates in milliseconds;
  thicken validation cost matches a 16-face C09 part. No builder changes the
  complexity of any shared evaluator path.

## 7. Open-shell-1 profile (normative stage list)

An open shell is published only if `brep_checked` with `P_open_shell` returns Tok.
Stages, in order: incidence; edge-use with the open rule (boundary edges used
exactly once, interior edges once each way); loop-closure-or-trim; face-kind;
ownership with the open rule (shells may be open, faces owned exclusively);
embedding; vertex-link (vacuously true under the open profile); shell
connectivity; coincident vertices; segment crossing; orientation (determined
faces only). Any failing stage refuses publication with the uncertain verdict
naming the stage, exactly as manifold-solid failures do.

## 8. Deferrals (explicit, carried, not silent)

- D-surf-queries: mass, extrema, section and tessellation run over open shells
  with shell semantics but are not certified there; only `surf` is the certified
  open reporter. dist/classify/check/interf/clearance/wall refuse by name.
- D-surf-gensec: sweep-open admits rect profiles only; slanted (cone-wall)
  profiles refuse `sweep-profile-not-admitted` although the shared sector
  machinery could build them. Admission needs per-wall cone areal certification.
- D-surf-thickcurv: thickening curved (non-rect) patches and cone-wall sectors
  is refused; exact offsets of bicubic/conical walls are not representable.
- D-surf-360: 360° sweep-open refuses; a closed tube has no boundary and adds
  nothing over C09 sweep.
- D-surf-est: patch area and boundary-curve lengths are subdivision estimates,
  not certified intervals; the oracle cross-checks them within 1%.
- D-surf-checkbez: ducts are certified at build time (all eleven manifold
  stages including embedding), but the `check` query reports
  `face-check-unsupported` / `face-face-uncertain` on their bilinear-bezier
  walls — the same verdict C09 tapered lofts carry, since face-check does
  not cover bezier faces. Slabs and sectors check `ok:`.
