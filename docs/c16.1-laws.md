# C16.1 sheet metal — laws

15 laws in 3 families over `src/c16/sheet.bend`. Every law passes
`tools/laws/check.sh` under `--check-only` and `--verdict`; every
family kills its planted mutant in `tools/laws/mutate.py`.

## F1 profile topology (2)

- `sh_loop_closed`: for every profile key, dimension, radius, hem
  and rotation argument, the produced profile and its 180-degree
  rotation are linked (head starts at the path start, every
  segment starts where the previous ends) with every endpoint
  index below the point-table length. Proved by case over the 12
  finite keys; the rotation shares segments definitionally.
- `sh_rot_len`: rotation preserves the point count (list
  induction, C15 rewrite form).

Helpers `sg_a/sg_b/below/linked/idx_closed` live in LAWS.bend
(C09 precedent). Mutant: loop edge skips its successor.

## F2 flat-pattern counts (3)

- `flat_rows_len`: one row per bend (induction over the
  production recursion `rows_go`, whose index the law carries).
- `flat_rows_nil`: no bends, no rows.
- `flat_legs_flat`: the blank develops to its single length run.

Mutant: rows drop every bend row.

## F3 refusal terms (10)

`base_go_false`, `fin_go_false`, `ang_go_false`,
`edge_go_false`, `rt_go_false`, `size_go_false`, `len_go_false`,
`k_go_false`, `gram_bad_base`, `gram_bad_edge`: when a gate
boolean is false on the production path, evaluation refuses with
the exact §4 term. Each quantifies over the gate context (C15
`st_go_false` form). Mutant: bad angles accepted.

## Evidence split

Proven: loop linkage + index validity, row/run counts, refusal
terms. Pinned (fixed inputs, bit-exact): gate outcomes and
first-wins order, chain selectors, seg/arc/face counts, volumes,
allowances, developed intervals, rendered fields, op tags, parse
shapes, boundary values. E2E: 3D solid closure per profile
(check-ok, exact faces/cylinders/volumes/bboxes), oracles,
param propagation, STEP/tessellation independent readers, every
refusal verbatim with no publication.

## Deviation from the plan

The plan sketches F1 as `bend_closed_solid`/`hem_closed_solid`
in the C09 `closed_solid` pattern. That pattern fits direct
`pack()` construction; C16.1 builds through `op_prism`
(fillet-edge precedent), where 3D closure is inherited, not
constructed. Stating `closed_solid` over prism output would
unfold the whole prism builder symbolically (the AGENTS.md
overflow warning); writing parallel explicit builders just for
laws would prove a model, not the shipped geometry. F1 instead
proves the real 2D invariant the builders own (linkage +
validity, quantified over every production profile) and leaves
solid closure to the inherited certificate plus per-profile
runtime evidence. The added `bend-consumes-face` refusal and its
gate law close the dimensional gap the plan list left open.
