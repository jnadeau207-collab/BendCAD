## 5. Audit fixes applied before commit (all probe-observed)

The as-landed packet carried four observed-bug pins (neg tests
asserting behavior the contract forbids) plus one comment-promised
pin that did not exist ("t=khi pinned after probing"). A code-level
audit reproduced each, fixed src, and converted every pin to the
corrected expectation with a matching law. No test was weakened or
deleted to manufacture green: total checks conserved (317 -> 317).

5.1 NURBS span clamp off-by-one (src/c03/ops.bend, nurbs_eval_go).
Was: span clamped into [3,nk-4]; at t = khi the window k[s-2..s+4]
overran by one, took the zero-fill path, and returned
numerical-uncertainty (probed: `nurbs_eval(nbk1(),1.0,9n)` ->
uncertainty while t=0.0/0.5/0.999 were ok). Fix: clamp into
[3,nk-5] (one line + `nk5` binding; bad counts still route to
invalid-input through the unchanged `valid` gate). Now: t=khi
evaluates to the exact endpoint (1,1,1) bits 4607182418800017408×3,
and zero-fill is genuinely unreachable (Part-B machine check).
Pins: law `nev_t1` + `pos-nev-t1`; `neg-bug-nev-t1` removed from
neg (moved, not dropped). Contract §7 amended (nk-5 + rationale).

5.2 Degenerate pdom_wrap published ±inf (src/c03/ops.bend).
Was: `pdom_wrap` gated finiteness but not `lo < hi`, so
Dom{DBL_MAX,0} published ok(-inf) and Dom{0,-DBL_MAX} published
ok(+inf). Fix: conjoin `F64.is_lt(lo,hi)` into the entry `ok`
(pipeline step 2: degenerate domain -> invalid-input). Now both
fixtures return invalid-input; valid-domain wrap provably cannot
overflow (t+span < hi, t-span > lo — stated argument, §4).
Pins: laws `wrap_degen1/2_inv` + `neg-wrap-degen1/2`. Valid wrap
unchanged (`wrap-25` -> 15, all wrap laws green).

5.3 Far-field sph_project published the center (src/c03/ops.bend).
Was: q=(DBL_MAX,DBL_MAX,0) overflows |q-c| to +inf; r/inf = 0
collapsed the projection to (0,0,0) — the sphere CENTER — published
as ok. Fix: thread `T.is_finite(n)` into `sph_proj_zero/go`;
nonfinite norm -> numerical-uncertainty (pipeline step 5: true
overflow), keeping coincident (n = 0) -> invalid-input. Now:
far -> uncertainty, center -> invalid, (2,0,0) -> (1,0,0), all
probed. Pins: law `sphp_far_unc` + `neg-sph-far`. Contract §9
amended (far-field example).

5.4 Native-lane arity failure in neg_g7 (tests only, no src change).
Was: `bend tests/c03/neg.bend -o native` failed with "an arity over
255". Bisection: groups g1..g6 build alone; g7 fails alone; a
singles-only g7 builds — the trigger is calling a big op 3× inside
one Bool tree (x/y/z component reads), same class as C02 D2.
Fix: `C.gres_p_is_zero` helper in tests/c03/check.bend (single call,
C02-D2 let-binding shape); f156/f157/f158 rewritten to use it.
Native neg now builds and runs 163/163.
