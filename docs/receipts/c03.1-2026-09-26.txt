## 5. Fixes applied (all probe-observed before pinning)

5.1 Centralized validity layer (src/c03/types.bend). New:
`dom_valid`, `ln_valid`, `cc_valid`, `rq_valid`, `sp_valid`,
`cy_valid`, `co_valid`, `to_valid` — finiteness + shape each.
All eight `mk_*` constructors consume them (identical conjunctions,
single source). Closes audit blockers #1–#4 structurally: no more
per-site reconstruction of validity.

5.2 Evaluator boundaries (src/c03/ops.bend). Every public evaluator
now consumes the layer: `dom_mid/len/clamp/split_lo/split_hi` +
`pdom_wrap` (identical conjunction, centralized); `line_eval/der/
project/dist`; `circ_checked/eval/der/seam/bbox` (identical
conjunction, centralized); `rqb_eval/der/bbox/disc`; `sph_val/grad/
project/pole_n/pole_s`; `cyl_checked/val/grad`;
`cone_checked/val/grad/ax`; `tor_checked/val/grad`. Raw zero line
directions, negative/zero conic weights (restoring the BN-10 `D>0`
certificate), negative/zero quadric radii/slopes, and degenerate
domains now fail as `invalid-input` at evaluator entries. Pins:
41 laws (§2) + `neg_g8` (28 checks).

5.3 Scaled sphere projection (src/c03/ops.bend, `sph_proj_q_raw`).
`c + (r/n)*m` → `c + r*((m/M)/(n/M))`, `M = max|m_i|`; the scalar
`r/n` is never formed. `n/M` in `[1,√3]`, `m/M` in `[-1,1]`, result
re-validated. A nonfinite norm still → uncertainty, coincidence
still → invalid. Closes audit blocker #5 (genuine numerical
robustness bug; true threshold §4). Pins: laws
`sphp_faraxis/minr/farctr_ok` + `pos_g7` (4 checks incl. mixed
MAX/MIN components).

5.4 Subnormal `d.d` arm (src/c03/ops.bend, `line_proj_go`/
`line_dist_go`). Zero direction now fails at the validity gate
(still `invalid-input`); `d.d == 0` past it is subnormal underflow
→ `numerical-uncertainty`, never misattributed as malformed input.
Pins: laws `lproj/ldist_tiny_unc` + `neg-lproj/ldist-tiny`.

5.5 Two re-pins (src fixes with corrected expectations, none
relabeled): `sphp_345` x `...012 → ...011` (correctly-rounded 0.6;
the new spelling is also the more accurate one); `dmid_ovf_unc` /
