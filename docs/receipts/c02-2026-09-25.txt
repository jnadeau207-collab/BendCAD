## 6. Defects found and fixed during implementation (both RED before)

D1 — 3x3 P/N split by cofactor position (wrong: a +cofactor triple
can be negative). The oracle caught it (`o3-neg` would certify pos
for true det −1). Fixed to a value-sign split over the six signed
triples (`fpos`/`fneg`, `ops.bend`); pinned by `o3-neg`/`o3-pos`
(P0/N0 shortcuts) and 308/290/198-case o3/ic/is differentials.
D2 — fork C-backend miscompile (not a C02 logic defect): a nested
`Bool.or` of 3+ user-def calls sharing binders returns True on the
native lane (interp/JS correct), which made 5 suite checks fail
natively (`pos-o2-ccw/cw/flip`, `pos-o3-neg`, `neg-o2-ovf`).
Bisected over 7 probes to this minimal repro (`probe7.bend`,
hash §1): `Bool.or(qq(ax,bx), Bool.or(qq(bx,cx), qq(ax,cx)))`
with `qq` a 2-arg `F64.is_eq` wrapper gives F on interp, T on
native; the `and` shape is fine. C02 works around it by let-binding
each repeated-point test before combining (`ops.bend` NOTE at
`pteq2`, contract §10) — no semantic effect: all three lanes agree
byte-identically on suite + stress (lands the 5 checks green).
