## 5. C08 latency: shell item closed, D2 re-measured

The C09.1 §3 deferral (`shell.closed_box` 2.41 s vs < 1 s) is
closed: the identical journey now runs in 0.89 s with
byte-identical verdicts (old-vs-new `diff` on all five node lines:
empty; volume interval bit-identical to the C09.1 baseline).
Root cause was algorithmic, in `src/c07/emb.bend`: the
face-face rank `m2` evaluated point-in-face member tests whose
result the rank provably discards (any zero side ranks 10 whatever
the other side computes), and plane×quadric pairs ran the
expensive quadric member before the cheap plane test. The fix
short-circuits both (`m2_fin_b` returns 0 on a zero pre-side,
`m2_ma` returns 0 on a zero member, `ff_go` k=4 tests the plane
face first). The rank is identical on all sixteen input
combinations, so no finding can change; the probe pair that cost
0.19 s now costs 0.03 s with `nfi=0` before and after.

Same-tree re-measurement of the c08 D2 cases: identical
16.53 s → 0.03 s (budget met, assertions unchanged),
contact.face journey 5.46 s, slanted.union journey 20.80 s (from
100.37 s; run-to-run variance here is ±0.2 s). Contact and
slanted stay owned by the latency packet.

D2 probe (closing kernel, 16 cores; CLI-level only — `perf`
is absent here and the binary carries HVM-runtime symbols
only, so OS attribution was infeasible and per-pair /
per-C04-stage timing still needs an instrumented build).
`check`/`tess` re-evaluate the whole design first, so proper
costs are totals minus re-eval: slanted build (nodes 1–3)
0.01 s, union (node 4) 21.45 s, check_proper (node 4)
21.1 s, check_proper (single prism) 19.8 s, tess_proper ~0 s.
`check_s` runs solid_fi + emb_fi + coin_contact only
(`src/c06/cli.bend`:541–553: no C04 stages, no
classify/assemble), so union − check nets stage10 +
classify + assemble ≈ 0.3 s: the ~21 s slanted residual
sits in the emb pair machinery (plus solid_fi/coin), not in
C04 validation or boolean assembly. Contact splits per
boolean: face 1.85 s, edge 0.94 s, vertex 0.82 s,
intersection 1.68 s (the journey is four booleans plus ~0.1 s
of builds); check_proper (face union) 1.9 s ≈ union_face,
same inference, and all contact ff pairs are plane-plane
ruled-skips, so contact cost is ee/ef fuel-40
discriminators only. Census from apply output: slanted

(`src/c07/emb.bend`: x-sorted sweep over u==0 edges plus
