# C16.2 receipt — 2026-10-15 (surface modeling closed)

C16.2 adds open-shell surface modeling on top of C16.1: loft-open walls,
sweep-open walls, bicubic patch cowls, the certified `surf` boundary reporter,
and thicken-open panels (slabs, ducts, sectors) that close to ordinary solids.
Four new ops (`loft-open`, `sweep-open`, `patch`, `thicken-open`), one new verb
(`surf`), one new MCP tool (`surface`), 17 new laws, 72 new pins, 12 E2E and
28 negative journeys. Every gate below ran on the final tree with the final
binary unless a section says otherwise.

## 6. Semantic bugs

Seven, each fixed at the root cause with a witnessing journey, pin or law:

1. `sw_rect_of` seeded its min/max fold with `F64.max(1,0)`/`neg(1)`, so any
   profile outside [−1, 1] misranged and sweep-open refused. Fix: head-seeded
   `sw_rect_go`. Witness: sweep-open smoke + `rect_sec` pin.
2. Taper-duct walls used plane frames that embedding cannot round-trip
   bit-exactly (`trim_uv` projects, `plane_eval` reconstructs; only axis
   frames and bezier corners are exact). First fix (Gram–Schmidt) attacked
   the wrong layer; the real fix represents all eight duct walls as
   bilinear beziers through exact corners, like C09 loft walls. Witness:
   `loft.taper` journey + `stv_duct` pin. Side effect, honestly carried:
   duct walls read back as STEP BSPLINE (8+8 split asserted) and the `check`
   query reports the C09-identical bezier verdict (D-surf-checkbez).
3. STEP exported open shells as CLOSED_SHELL: the packer marked every shell
   outer. Fix: kinds derived from use counts (§5). Witness: `step.open` neg,
   which previously received a 78-entity file.
4. `archive` wrote open-shell archives `reopen` then rejected under the solid
   profile. Fix: refuse at write time by name. Witness: `archive.open` neg;
   `surf.replay` archives the thickened solid instead.
5. Tessellation flattened curved patches (boundary-only fans). Fix: 8×8
   interior grid for curved bezier faces. Witness: `surf.tess` crown 0.162.
6. The grid, applied uniformly, unwelded planar-patch solids (c08
   `slanted.mesh` watertight/euler, c10 `tess.prism_slant` counts regressed).
   Fix: planarity gate — planar bezier faces keep the old ring path bit for
   bit; only curved faces grid. Both regressions restored, cowl kept.
7. Use-counting at O(U²) blew the perf.holes400 build budget (4.16s vs 2.0s).
   Fix: sort-based singleton scan, O(U log U); build now 0.16s. Witness:
   `perf.holes400` green with 12× headroom.
