## 5. Design record (what was built and checked)

The hole-open fix (stage L part 1, `src/c04/ops.bend`):
`loop_orient_c` took no kind and required every loop's Newell
winding aligned with the `same`-adjusted surface normal
(`0 < dot`). Hole (inner) loops wind OPPOSED by convention, so
any face carrying a hole was unrepresentable — `b_hole()` was
rejected (pre-fix record: the stale 20:27 log's
`pos-ck-hole-open FAIL [invalid-input]`). The fix threads
`Ty.lp_kind(lp)` through `hlp_orient_go` into `loop_orient_c`,
which now requires `0 < dot` for outers (`lkind_tag == 0`) and
`dot < 0` for holes (`Bool.pick` on the kind). Skip policy
unchanged: zero-area winding or an unavailable normal still
skips (passes); only a strictly wrong-signed finite dot fails.
Pinned: `pos-ck-hole-open` accepts under `P_open_shell`;
`neg-ck-hole-bad`/`neg-ck-hole-bad2` (wrong-signed windings)
reject; `ck_hole_ok`/`ck_hole_bad`/`ck_hole_bad2` laws close.

Propagation rewrite (stage L part 2): same-flag agreement
across distinct faces is deleted as a validity rule — each
`same` is relative to its own surface parametrization (plane
frame, Bezier du/dv handedness, quadric gradient side), so
adjacent faces legitimately differ (e.g. two planes with
opposite natural normals need DIFFERING `same` for consistent
outward normals). Same-equality both rejected valid solids and
admitted invalid ones. The replacement is per-use local
coherence: each use's owning loop winds correctly (kind-aware)
for its own face; cross-face validity stays opposite-use
(stage C) + per-face winding-vs-own-normal. Pinned:
`pos-ck-oriprop`/`pos-ck-diffparam` accept (+ `ck_oriprop_ok`/
`ck_diffparam_ok` laws); `pos-prop-oriprop` code 2n → 3n;
`neg-ck-oriprop` removed; `b_invface` still rejects via part 1
(`pos-prop-invface` code 2n).

Hierarchy ownership (stage F, +13 defs): `hlp/hfa/hso_free_of`
+ `hlp/hfa/hso_nodup_c` + `hlp/hfa_list_free_of` +
`hlp_free_of_fas`/`hfa_free_of_shs` + `fas_loop_own_c` (each
loop owned by at most one face) + `shs_face_own_c` (each face
by at most one shell) + `cp_so_own_c` (each solid listed at
most once in the compound root). Ownership reads member lists
only (append-only unreachable-history rule, contract §1/§6):
unreferenced slots never reject. Open profile checks
