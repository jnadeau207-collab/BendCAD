# C16.1 sheet metal — contract

Sub-packet C16.1 of MASTER_PLAN §10 C16: flat blanks, straight bends
and closed hems as first-class solids with certified flat patterns.
`(flat L W T)`, `(bend BASE (edge N) R DEG)`, `(hem BASE (edge N) L)`
and the `flat` query ship on the real CLI+MCP paths. All dimensions
stay expressions of the design parameters: param edits propagate
through the part and its flat pattern.

## 0. Interpretations

- INT1: N selects the bend placement among the admitted (end,
  direction) pairs: 0 = +x end up, 1 = +x end down, 2 = -x end up,
  3 = -x end down. Width-edge bends need a different construction
  (D-sheet-side).
- INT2: the bend line sits at blank mid-length (legs L/2); the flange
  straight is L/2 - (R+T). No flange-length argument exists on the op.
- INT3: after a bend, a hem folds the bent flange tip only. Hems of
  the opposite flat leg and bends after hems are refused (D-sheet-hembend).
- INT4: `bend-consumes-face` (invalid-input) is added beside the plan
  list for blanks too short to bend; the plan list has no dim refusal
  for bends.
- INT5: `flat` on a flat blank is admitted: zero bend rows, one run,
  developed = blank length.
- INT6: U channels need equal radii; asymmetric and Z (opposite
  direction) doubles are refused (D-sheet-asym, D-sheet-z).
- INT7: pockets, holes and zones do not apply to sheet bodies. They
  answer the existing refusals verbatim
  (`features-need-an-extruded-body`,
  `topology-not-certified-over-zone`); every sheet op carries an
  explicit zone arm. Sheet features are deferred (D-sheet-features).

## 2. Operations (normative)

`(flat L W T)` builds the block [0,L]x[0,W]x[0,T] through the
certified prism path with native measures. `(bend BASE (edge N) R
DEG)` and `(hem BASE (edge N) L)` flatten the op chain to one sheet
profile (bend frame: length along x, thickness along y, width
extruded along z) and build one solid through `op_prism` with the
closed-form volume below. Nothing is ever booleaned. Intent
material is `create` for flat (baseless) and `add` for every bend
and hem (each stores strictly more volume than its base at R/T
>= 1: the 90/180/U excess over the blank stays positive above
R/T 0.376, hems add exactly their fold). Admitted
chains: flat; bend(flat); bend(bend(flat)) (U: opposite ends, same
direction, both 90, equal radii); hem(flat); hem(bend(flat))
(single 90, hem end = bent end); hem(bend(bend(flat))) (tip fold on
one U flange). All other chains are refused by §4.

Profile inventory (k): 0/1 single 90 up/down, 2/3 single 180
up/down (two 90 arcs per turn, never a 180 arc), 4/5 U up/down,
6/7 flat hem top/bottom, 8/9 tip fold up/down, 10/11 U tip fold
right/left. -x variants rotate 180 degrees in-plane (orientation
preserved, same combinatorics). Faces: 90: 10, 180: 10, U: 14,
flat hem: 8, tip: 12, U tip: 16, flat: 6.

Volumes (stored, oracle-checked): single 90/180 legs plus
quarter/half annulus `(pi/4|pi/2)(Ro^2-R^2)`; U exact
`l*t + 2t(Fu-t-R) + (pi/2)t(2R+t)` with no inverse trig; hems add
exactly `Lh*t*w`. Gate order on the production path:
base, finiteness, angle, edge, grammar, R/T, size, hem length;
first failure wins.

## 3. Flat pattern (normative)

`flat NODE KLO KHI` refuses unknown/failed nodes, non-sheet nodes
and K zones outside 0 < KLO <= KHI < 1, then prints: header
(`flat node N bends B hems H`); one `bend I edge N deg D r R
allowance [LO, HI] certified` row per bend with
A = DEG/360 * 2pi(R + K*T) over the zone in outward-rounded
interval arithmetic; one `hem I edge N len L` line per hem; the
developed runs (`legs [...]`); `developed [LO, HI] certified`;
`blank L W`. Developed runs per chain: flat [l]; single [L1, F1];
U [Fu, web, Fu]; flat hem [l, t, Lh]; tip
[L1, F1-Lh, t, Lh, Lh]; U tip [Fu-Lh, t, Lh, Lh, web, Fu].
Developed = runs plus allowances, folded left to right from zero.

## 4. Refusals (verbatim)

| why | kind | fix |
|---|---|---|
| bend-angle-not-certified | unsupported-op | bend 90 or 180 degrees |
| bend-edge-not-admitted | unsupported-op | bend or hem edge 0..3 / bend opposite ends alike, hem the bent end once |
| bend-radius-too-tight | unsupported-op | keep inner radius over the certified R/T bound (1.0) |
| bend-base-not-admitted | invalid-input | bend flat or single-bent sheet, hem once at most |
| bend-consumes-face | invalid-input | keep the blank longer than twice outer radius |
| hem-consumes-face | invalid-input | keep the hem shorter than its leg |
| degenerate-feature | invalid-input | give finite positive lengths for the blank, radius and hem |
| flat-needs-sheet | invalid-input | run flat on a flat, bend or hem node |
| bad-k-zone | invalid-input | give a K-factor zone with 0 < KLO <= KHI < 1 |
| unknown-op | invalid-input | use ... flat, bend, hem or import |
| unknown-node N | invalid-input | name an evaluated node |
| error: node N; nothing flattened | — | failed node |

Gate booleans are proven (§5); grammar composition, first-wins
order and boundary values are pinned; journeys assert every row.

## 5. Laws and pins

15 laws in 3 families: F1 profile loop linkage + index validity
over all 12 builders and their rotations, rotation length; F2
flat-row counts (induction + empty), blank develops to one run;
F3 one refusal term per gate (base, finiteness, angle, edge, R/T,
size, hem length, K, grammar x2). 3 mutants (loop edge skip, row
drop, bad-angle accept), one per family. ~90 pins: gate outcomes,
chain selectors, profile/arc counts, volumes, allowances and
developed intervals to the bit, row/leg fields, op tags/names/
bases, parse + roundtrip, boundary values (R/T, size, length, K).

## 6. Journeys

E2E (11): flat blank; single 90 with flat oracle; 23-variant
sweep (all builders, orientations, rotations); U+hem bracket with
flat oracle; hem flat; 180 fold; param edit propagation with
sensitivity slope; tessellation + trimesh bbox/volume; STEP export
+ build123d read-back (1 solid, 16 faces, 4 cylinders, volume);
show/apply replay + archive/reopen; MCP parity. Neg (25):
every §4 row verbatim with design unchanged and no artifact,
plus unknown/failed flat nodes, zone refusal and the inherited
feature-base refusal.

## 7. Complexity and budgets

Profile build is O(1) (bounded point/seg tables); flat rows are
O(bends); chain flattening is O(nodes) fuel-bounded; eval cost is
one prism build plus C04/C07. Budgets: single apply+eval+flat
under 1s; full 23-variant sweep under 60s; pins under 300s.
Receipt carries measured latencies; a miss blocks the packet.

## 8. Deferrals and kernel limits

D-sheet-z (Z/S doubles), D-sheet-asym (unequal U radii),
D-sheet-side (width-edge bends), D-sheet-hembend (flat-leg hems
on bent parts, bends after hems), D-sheet-features (pockets/holes
on sheet bodies need a base_kind extension; refused today).
OM-rtfloor: the true C04/C07 floor below R/T 1.0 is unprobed;
1.0 is the enforced verified floor. G3 §3: contact unions are
designed around (direct one-solid construction, check-ok +
volume/face journeys); side-blind obstacles are inherited (no
face-feature chaining exists on sheet; the feature-base refusal
is pinned); thin radii are gated (R/T bound + boundary pins);
ring pockets are unreached (features refused first; pinned).
