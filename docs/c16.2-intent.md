# C16.2 intent — why surface modeling looks like this

C16 exists so a cowl panel, a duct and a bent sector can be built, measured and
closed into solids without leaving certified geometry. C16.2 does that with four
verbs and one query, and refuses everything it cannot certify.

Loft-open and sweep-open reuse the C09 classifiers and builders minus caps. The
shared classifier is the point: an agent that learned C09's admitted domain
already knows C16.2's, and every inherited refusal means exactly what it meant
in C09. Sweep-open additionally narrows profiles to rects, because only
cylinder and plane walls carry exact wall areas and exact thickened volumes;
a slanted profile would build a fine open shell whose area the kernel could not
certify, so it refuses with its own name instead of publishing an estimate
disguised as a measurement.

Patch takes 16 control points and builds exactly one bicubic face. The control
net is the contract: rows, columns and corners must be distinct, the control
box contains the surface, and anything curved reports estimates labeled as
estimates. A curved cowl can be surfaced and measured but never thickened,
because the exact offset of a bicubic is not a bicubic; only exact rectangles
with straight rows close into slabs.

Thicken-open closes what the other three open. Ducts and sectors close into
tubes with a through-channel — a real duct stays open at both ends — which is
genus 1 on a single shell, the only topology the packer can express. The
volumes stay closed-form (frustum and annular-sector differences), so a
thickened panel measures exactly like a C09 part and exports to STEP with
plane, cylinder and bilinear-bezier faces only.

`surf` is the honest reporter for everything open. Stored mass records on open
nodes say enclosed volume 0 — true, since an open shell encloses nothing — and
a loose area bound; solid-semantics queries (check, classify, dist, interf,
clearance, wall) refuse by name rather than certify nonsense. Boundary edges
carry durable canonical names so edits propagate through reports.
